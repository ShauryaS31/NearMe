## Mac setup

Needs Xcode with the iOS 26.5 SDK and an iPhone simulator runtime (Xcode > Settings > Components).

```bash
brew install xcodegen
cp -n Secrets.xcconfig.example Secrets.xcconfig          # optional: ElevenLabs key
cp -n Config/Team.xcconfig.example Config/Team.xcconfig  # needed for a real iPhone only
```

| Command | What it does |
|---|---|
| `bash scripts/mac-run.sh` | Pull main, generate the project, build for the newest iPhone simulator, boot, install, launch |
| `bash scripts/mac-run.sh quick` | Build the current checkout without checkout/pull; generate only when needed, reuse a booted iPhone simulator, incrementally build, install and launch; print elapsed seconds |
| `bash scripts/mac-run.sh test` | Run fast NearMeTests on that simulator; real-model eval is skipped |
| `bash scripts/mac-run.sh eval` | Run the three opt-in real-model sentences; print EVAL lines and test results, with the full log in `build/xcodebuild.log` |
| `bash scripts/mac-run.sh device` | Build, install and launch on a connected iPhone (signed with your Personal Team; simulators are never chosen; add `--device=NAME` to pick one) |
| `bash scripts/mac-run.sh report` | Write and push a results file in docs/mac-results/ |

Add `--current` to build the checked-out branch without switching to main. Both local files are gitignored; never commit them. `NearMe.xcodeproj` is generated by XcodeGen and gitignored. CI is manual only (Actions > CI > Run workflow).
